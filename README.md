 # E-commerce Churn & LTV Prediction Web App

This is a Streamlit-based machine learning web app that works with any e-commerce CSV dataset.

## Features
- Upload any CSV file
- Predict:
  - Churn only
  - LTV only
  - Both churn and LTV
- Automatic column detection
- No manual column mapping required
- Missing value handling
- Automatic encoding
- Random Forest models
- Download predictions
